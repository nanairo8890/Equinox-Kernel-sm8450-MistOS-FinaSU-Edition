# Equinox MistOS FinaSU Edition 1.5

Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
FinaSU edition by **Nanairo8890** with LF52406's permission.

Same kernel as r2 (`5.10.269-Nanairo-FinaSU`, identical `Image`). This version changes the installer: it
checks the ROM's vendor modules before flashing, so the zip can be flashed on any AOSP ROM for mondrian
without risk.

## Files

- `Equinox-5.10.269-FinaSU-1.5-mondrian.zip`: AnyKernel3 zip. Flash it from a recovery or a kernel
  flasher; it checks the ROM's vendor modules and then replaces only the kernel `Image`, keeping the
  ROM's ramdisk, header and bootconfig.
- `Equinox-5.10.269-FinaSU-1.5-mondrian-checkonly.zip`: the same package, named so that it only runs
  the check and flashes nothing. Use it to find out whether your ROM is compatible.
- `FinaSU_v1.2.1_33074-release.apk`: the official FinaSU manager (`me.yuki.fina`), from FinaSU's release.
- `CHANGELOG.en.txt`, `CHANGELOG.es.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog.

## Before flashing

- Back up your `boot` partition first.
- If you update your ROM, flash the zip again afterwards, because the ROM ships its own kernel.
- Choose **NoMount** as the mount backend in the FinaSU manager. If you had the NoMount metamodule
  installed, remove it.

## What 1.5 adds over r2

- **Vendor module check.** The kernel only works with the ROM's `vendor_boot` and `vendor_dlkm` modules
  if they were built for the same symbol CRCs. Before writing anything, the installer reads those
  modules and checks them with `kmicheck` against the kernel's own symbol table. If a module would be
  rejected (different CRC, a symbol this kernel does not export, a duplicate export or a different
  vermagic), it lists the modules and stops, leaving the phone as it was. Modules in
  `modules.blocklist` are not checked. A zip whose name contains `nocheck` skips the check.
- **`checkonly` zip**, which runs the check and flashes nothing.

## Compatible ROMs

Checked against this kernel's vendor module CRCs:

- **Compatible:** MistOS 5.1 Beta / 5.0 Alpha; the latest builds from Keosh with the kernel
  `5.10.269-gki-g1598dc02ea84`: crDroid 12.12 (20260928), Evolution X 11.11, Infinity-X 3.12 (VANILLA,
  GAPPS core and extra), Lunaris 3.12 (VANILLA and GMS), LineageOS 23.2 (20260929) and Axion 2.8 (VANILLA
  and GMS); Infinity-X 4.1 by LF5 (17.10.2026); crDroid 12.12 by Taha Keles (20260930).
- **Not compatible:** AOSPA calcite and PenguinOS celerity. They use their own kernel
  (`5.10.269-beryl-7156c6f9fb`) and the installer stops on them.
