# Equinox MistOS FinaSU Edition 5.10.269 r2

Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
FinaSU edition by **Nanairo8890** with LF52406's permission, for **MistOS 5.1 Beta** (Android 17).

## Files

- `Equinox-5.10.269-FinaSU-mondrian-20261027.zip`: AnyKernel3 zip. Flash it from a recovery or a kernel
  flasher; it only replaces the kernel `Image` and keeps the ROM's ramdisk, header and bootconfig.
- `FinaSU_v1.2.1_33074-release.apk`: the official FinaSU manager (`me.yuki.fina`), from FinaSU's release.
  Install it to manage root, modules and SUSFS. It coexists with other KernelSU-family managers.
- `CHANGELOG.en.txt`, `CHANGELOG.es.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog.

## Before flashing

- Back up your `boot` partition first.
- After flashing, `adb shell su -c "dmesg | grep -i 'disagrees about version'"` should print nothing.
- If you update MistOS, flash the zip again afterwards, because the ROM ships its own kernel.
- Choose **NoMount** as the mount backend in the FinaSU manager. If you had the NoMount metamodule
  installed, remove it: FinaSU uses the built-in NoMount driver, so the metamodule is not needed.
- For the BakaSU edition of this kernel, see [nanairo8890/Equinox-Kernel-sm8450](https://github.com/nanairo8890/Equinox-Kernel-sm8450).

## What r2 adds over r1

- **Kernel name** `5.10.269-Nanairo-FinaSU`.
- **More symbols hidden from `/proc/kallsyms`**: FinaSU exports many driver symbols whose names do not
  start with the usual KernelSU/SUSFS prefixes, so SUSFS's filter left them visible. The filter now also
  hides those (`crown_manager`, `apk_sign_keys`, `dynamic_manager_*`, `selinux_hide_*`, `sulog_*`,
  `avc_spoof_*`, and more). Each prefix was checked against a clean Equinox build, so only FinaSU's own
  symbols are hidden; generic names shared with the stock kernel are deliberately left alone.

## This edition

- **FinaSU** `v1.2.1` (33074, commit `be19eb90`) by LyraVoid, built in. Uses the official FinaSU manager.
- **SUSFS** v2.3.0 (`eb95da0`), with a use-after-free fix in the priority-uid filter.
- **NoMount** v2.2.0 by maxsteeel built in, used as FinaSU's NoMount backend; deref3046's fix included.
- **BBR** default. DroidSpaces, Goodix fixes, Clang CFI and MODVERSIONS as in Equinox.

## Checks

- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` is added).
- Vendor module CRCs match MistOS 5.1 Beta 20261025, 20261024, 20261023 and 20261011, and MistOS 5.0
  Alpha 20260914 (337 `vendor_boot` and 390 `vendor_dlkm` modules each).
- **Tested on the phone** (POCO F5 Pro, MistOS 5.1 Beta 20261025): boots, 0 vendor modules rejected,
  root works, SELinux Enforcing, no panics, and `/proc/kallsyms` no longer shows FinaSU's symbols.
